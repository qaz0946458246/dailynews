## 一、战斗核心：棍势与闪避

《黑神话：悟空》是国产3A标杆，战斗围绕**轻攻击攒棍势 + 重攻击爆发 + 闪避无敌帧**展开。

- 轻攻击四段后接重攻击可打出最高伤害；
- 闪避时机比格挡更重要，多数Boss招式都可完美闪避；
- 体力管理是关键，乱砍空体力等于送死。

## 二、变身系统是灵魂

不同变身应对不同场景：

| 变身 | 适用 |
|------|------|
| 猿形态 | 近身高爆发 |
| 虫形态 | 远程消耗 |
| 鱼形态 | 水下机动 |

## 三、装备与属性

不要盲目堆攻击，**防御与特殊效果**往往更实用。面对高伤Boss，适当堆减伤能显著降低难度。

## 四、Boss通用技巧

每个Boss都有固定招式循环，先**观察一轮不贪刀**，记住破绽再输出。二阶段通常只是招式变快，规律不变。
