# 王者荣耀：5v5 竞技的上分思路

国民手游《王者荣耀》拼的是 **操作 + 意识 + 团队配合**。

## 位置分工

| 位置 | 职责 |
|------|------|
| 对抗路 | 抗压、开团、前排 |
| 打野 | 控龙、抓人、节奏 |
| 中路 | 清线、支援、爆发 |
| 射手 | 持续输出（核心 C 位）|
| 辅助 | 保护、视野、开团 |

## 上分心法

- **补刀优先**：金币来自小兵，漏刀等于送经济；
- **看小地图**：每 3-5 秒扫一眼，防 gank、抓时机；
- **推塔 > 杀人**：击杀只是手段，推掉防御塔才是目的；
- **心态稳住**：逆风不投，顺风不浪。
