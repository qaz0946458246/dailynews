# 原神：开放世界的探索与养成

作为全球现象级开放世界游戏，《原神》的核心循环是 **探索 → 收集 → 养成 → 挑战**。

## 新手开局三件事

- **跟主线解锁传送点**：优先推进魔神任务，快速解锁更多传送锚点，后期跑图省时；
- **别乱用原石**：原石只抽 **限定角色池**，武器池和常驻池谨慎投入；
- **角色均衡养成**：主 C、副 C、辅助、治疗各养一个，避免队伍短板。

## 资源规划口诀

> 经验书给主 C → 突破材料按角色刷 → 圣遗物 45 级后再刷（前期别浪费体力）

## 实用小技巧

- 每天清 **每日委托**（60 原石/天，稳定来源）；
- 开图时顺手捡 **神瞳、宝箱**，提升神像等级加体力；
- 组队讲究元素反应：蒸发、融化、超导是伤害核心。
