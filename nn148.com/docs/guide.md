## 一、游戏阵营与目标

《Among Us》分**船员**与**内鬼**两大阵营。船员做任务修船，内鬼暗中破坏与击杀。

## 二、船员排查思路

- **跟任务进度**：任务条是唯一客观线索；
- **记行动路线**：谁出现在案发时间地点附近；
- **监控摄像头**：目击报告可信度最高。

## 三、内鬼伪装技巧

| 技巧 | 说明 |
|------|------|
| 假装做任务 | 靠近任务点装样子 |
| 制造不在场证明 | 提前与队友约定路线 |
| 引导投票 | 甩锅给真船员 |

## 四、会议发言逻辑

发言要**有信息量**：报路线、报任务、指认要有依据。无脑喊"我是好人"反而可疑。逻辑推理 + 演技，这游戏才好玩。
