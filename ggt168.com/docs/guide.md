## 一、围棋的基本规则

围棋目标是**围地多于对手**。黑先白后，交替落子，棋子无气则被提。

## 二、吃子的三种方式

- **紧气吃**：逐步收气直至对方无气；
- **抱吃**：包围后关门捉子；
- **征吃（扭羊头）**：步步紧逼迫使对方走入死路。

## 三、死活是核心功力

初学者每天做**3-5道死活题**，比多下棋进步更快。"做眼"与"破眼"是判断死活的关键。

## 四、布局三原则

| 原则 | 说明 |
|------|------|
| 占角 | 先抢星位、小目等角部 |
| 守边 | 角之后向边扩展 |
| 拆边 | 建立自己的势力范围 |

围棋是长期修炼，前100局重在理解"势"与"地"的平衡。
