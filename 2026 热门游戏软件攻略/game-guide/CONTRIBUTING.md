# 贡献指南

感谢你对本仓库的兴趣！欢迎通过 Issue 和 Pull Request 来完善这份游戏攻略。

## 📝 如何贡献

1. **Fork 本仓库**并克隆到本地；
2. 新建分支：`git checkout -b feat/your-topic`；
3. 在 `docs/` 下新增或编辑 `.md` 文件，遵循现有目录结构；
4. 提交前检查：
   - Markdown 格式正确；
   - 链接可正常访问；
   - 新增游戏请同步更新 `docs/game-list.md`；
5. 提交 PR，描述清楚改动内容。

## 📌 内容规范

- 以客观攻略、玩法技巧为主；
- 推荐通过官方正版渠道下载游戏；
- 保持友好、尊重的社区氛围。

## 🐛 反馈问题

如发现错漏或有改进建议，欢迎提交 Issue。
