## 一、钓鱼：被低估的赚钱方式

《星露谷物语》钓鱼前期难度高，**掌握节奏条**后收益可观，是早期重要收入来源。

- 不同水域/季节出不同鱼；
- 雨天海边能钓到高价鱼；
- 升级鱼竿（玻璃纤维→铱金）后可使用浮漂和鱼饵。

## 二、矿洞攻略

| 层级 | 要点 |
|------|------|
| 1-40层 | 铜/铁矿石，熟悉怪物 |
| 40-80层 | 金矿，出现骷髅 |
| 80层以下 | 铱矿，危险区备好血药 |

每层第**10层**有电梯存档点，务必激活。

## 三、装备与补给

- 带足**食物回血**，矿洞深处消耗大；
- 升级镐子提高效率；
- 幸运日下矿收益翻倍，看电视日历。

钓鱼+矿洞是中期资金与材料的核心来源，规划好节奏事半功倍。
